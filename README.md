# Data_analysis_Excel_projects
This repository contains my **Excel practice work and Data Analysis exercises**.

I am using this repository to build and improve my practical Excel skills through hands-on practice and small projects.

## Purpose

The main goal of this repository is to practice how Excel can be used to:

* Clean and organize data
* Analyze datasets
* Apply Excel formulas and functions
* Create Pivot Tables
* Create charts and visualizations
* Find trends and patterns
* Calculate important KPIs
* Solve basic business problems
* Present data in a clear and understandable way

## Excel Skills Practiced

* Data Cleaning
* Data Formatting
* Sorting & Filtering
* Excel Functions & Formulas
* IF / IFS
* SUMIF / SUMIFS
* COUNTIF / COUNTIFS
* AVERAGEIF / AVERAGEIFS
* XLOOKUP / VLOOKUP
* Text Functions
* Date Functions
* Conditional Formatting
* Pivot Tables
* Pivot Charts
* Charts & Visualization
* Basic Dashboard Creation
* KPI Analysis
